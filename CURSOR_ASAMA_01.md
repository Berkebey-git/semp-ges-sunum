# CURSOR — AŞAMA 1 / İLK İSTEM

Aşağıdaki metni Cursor Agent sohbetine bir defada yapıştır:

> Benimle adım adım SEMP Grup için prestijli bir **3D interaktif GES yönetim sunumu** geliştirmeni istiyorum. Önce `AGENTS.md`, `SUNUM_MIMARISI.md`, `README_ILK_BENI_OKU.md`, `data/belge_index.json` ve mevcut `index.html` dosyasını oku. `pdfler/` klasöründe tam 20 PDF, `sources/` klasöründe sayfa numaralı OCR gerektirmeyen metinleri bulunuyor.
>
> İlk görevin **mevcut çalışan demo özelliklerini koruyarak** kodu modüler, büyütülebilir Vite + React + TypeScript + React Three Fiber + Drei mimarisine taşımak. Bu aşamada 20 PDF'yi tek seferde Agent bağlamına alma; ilgili bölümün birkaç kaynak sayfasını seçerek kullan. Ana ekran, 3D çatı GES, çatı/arazi/yüzer seçimi, panel tıklama, finansal örnek hesabı ve 90 günlük yol haritası aynı işlevlerle çalışsın. Premium lacivert/turkuaz görünüm korunsun; mobil ve 16:9 projeksiyon için responsive olsun.
>
> Önce kısa görev planı üret, sonra dosyaları oluştur ve `npm install`, `npm run build` çalıştır; hataları gider. Kullandığın veri için kaynağı BXX/sayfa biçiminde göster. Varsayımsal hesapları kesin yatırım hesabı gibi sunma. Çalışma bitince çalıştırma komutlarını, değiştirilen dosyaları ve bir sonraki önerilen küçük görevi bildir. Kullanıcı onayı olmadan diğer aşamalara geçme.

İlk aşama bitince ikinci göreve `CURSOR_ASAMA_02.md` üzerinden devam et.
